# InStoreLook VC Demo

## Video

`instorelook-vc-demo.mp4` is a 32-second investor-facing concept/demo video.
It presents the problem, shopper journey, nearby discovery, India-first product
detail, retailer workflow, business model, and the funding narrative.

The upgraded cut uses cinematic motion graphics: layered depth cards, animated
background light, camera push-in, gentle rotation, shadows, and fade transitions
to create a modern 3D-style product-launch feel. It is simulated 3D motion
design, not a rendered Blender scene.

## Presenting live

Use `voiceover-script.md` while screen-sharing the deployed app. The strongest
live flow is:

1. Allow current-location access.
2. Show nearby stores and map details.
3. Open a product to show ₹ pricing, stock, and sizes.
4. Open directions or call the store.
5. Demonstrate the seller upload and AI-assisted product draft.

The MP4 uses designed product-demo slides rather than pretending that external
map inventory is guaranteed. In the live demo, clearly distinguish registered
InStoreLook inventory from external map places.
